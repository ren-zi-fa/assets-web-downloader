Asset Downloader is a browser extension that scans the page you are viewing and download it

## Install

- <img src="public/icon/chrome.svg" width="20" height="20" alt="Google Chrome"> **Chrome / Edge / Brave** — [Chrome Web Store](https://chromewebstore.google.com/detail/hgjmobeeoakacnbllmodianbiiofchjm?utm_source=item-share-cb)
- <img src="public/icon/firefox.svg" width="20" height="20" alt="Mozilla Firefox"> **Firefox** — [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/asset-downloader/)

## Build from source

```bash
pnpm install
pnpm dev
pnpm zip
```
