# Asset Downloader

Scan and download images, sprites, fonts, and audio from any web page.

## Install

- 🌐 **Chrome / Edge / Brave** — [Chrome Web Store](https://chromewebstore.google.com/detail/hgjmobeeoakacnbllmodianbiiofchjm?utm_source=item-share-cb)
- 🦊 **Firefox** — [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/asset-downloader/)

## Build from source

```bash
pnpm install
pnpm dev
pnpm zip
```
